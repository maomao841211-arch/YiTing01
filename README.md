# 608／609 課堂記分

- `index.html`：609 班，1–24 號；座位依新提供的「座位表-609.docx」。
- `608.html`：608 班，1–26 號；座位依「座位表-608.docx」。

直接用瀏覽器開啟各 HTML 即可使用，不需安裝套件。也可在此目錄執行 `python3 -m http.server 8000`，以固定來源使用瀏覽器本機儲存。

每個學生座位提供加 1 分、扣 1 分按鈕；下方記分板同步顯示累計分數。支援復原、CSV 匯出及需確認的全部清零。兩班以不同 localStorage 鍵分別儲存，609 沿用既有鍵，更新座位不會清除相同來源中原有的座號分數。

分數儲存在目前瀏覽器，沒有跨裝置同步；更換瀏覽器、開啟方式或清除瀏覽器資料前，請先匯出。
